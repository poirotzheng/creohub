# Support

- **Documentation**: start with `README.md`, then the user guide
  (`docs/40_creohub安装与使用教程.md`) and the developer guide
  (`docs/18_插件开发者指南.md`).
- **Questions / ideas**: GitHub Discussions (once enabled) or an issue using the
  feature template.
- **Bugs**: use the bug template and attach the output of `deploy\doctor.cmd`
  plus `logs\hub*.log` excerpts. Remove tokens/keys before posting.
- **Security**: see `SECURITY.md` — never open a public issue.
- **Commercial / enterprise**: `creohubsecurity@163.com`.

This is a community project. It does not provide PTC licenses or support for
Creo itself; contact PTC for product support.
